## 🛠️ Tech Stack Singkat
* **Framework**: Vite + TypeScript
* **Pose Estimation**: MediaPipe Pose / TensorFlow.js MoveNet (100% on-device, zero backend upload)
* **Game Rendering**: Phaser.js / HTML5 Canvas 2D
* **Testing**: Live QA testing bersama anak TK & SD Kelas 3
